# 🧠 Site de Psicologia

> Projeto desenvolvido durante o 1º ano do Curso Técnico em Desenvolvimento de Sistemas integrado ao Ensino Médio.  
> Trabalho em equipe com **6 integrantes** — fui responsável pelo **desenvolvimento front-end e design**, incluindo as telas de **Como Funciona**, **Consulta Online** e **Consulta Presencial**, com calendários interativos em JavaScript.

## 📋 Sobre o Projeto

- **Tipo:** Front-end apenas  
- **Objetivo:** Criar um site informativo de Psicologia com design responsivo, interativo e navegável  
- **Aprendizado:** Aplicação prática de HTML, CSS e JavaScript, incluindo desenvolvimento de **calendários dinâmicos** e organização de múltiplas telas  

---

## 🖥 Telas do Projeto

- Tela Home  
- Tela de Ajuda  
- Tela de Artigos  
- Tela de Cadastro  
- Tela de Login  
- Tela de **Como Funciona** ✅ (feito por mim)  
- Tela de **Consulta Online e Presencial** ✅ (feito por mim, com calendários JS)  
- Tela de Informações  
- Tela de Perfil do Usuário  
- Tela de Quem Somos  
- Tela de Suporte  
- Tela de Termos  
---

## 🚀 Funcionalidades

- Navegação simples e intuitiva entre as telas  
- Seções informativas sobre Psicologia  
- Calendários interativos para consultas online e presenciais  
- Design moderno e atrativo
